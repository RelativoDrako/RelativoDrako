# Repository Metadata Canonical

## Purpose

This file keeps public-facing repository descriptions consistent across the GitHub profile, GitHub Pages, and repository metadata fields.

It is not a deployment guide and does not define a public pinned-repository recommendation.

## Suggested descriptions

### probabilistic-seismic-risk-prototype
Local-first prototype for probabilistic regional seismic risk modeling in Mexico, with bounded analytics, SQLite authority, and publication-safe evidence artifacts.

### RelativoDrako.github.io
Professional landing page for systems architecture, critical and intelligent infrastructure, resilient operations, and public capability positioning.

### inventory-stream7-rescue
Cross-platform inventory, rescue triage, and install-path assessment for constrained Linux and Windows hardware.

### EdgeResilienceLab
Publishable work-in-progress architecture line for governed AI, resilient edge/OT systems, human-in-the-loop boundaries, auditability, recovery patterns, and local-first operational framing.

## Public positioning policy

- PSRP remains the flagship technical proof.
- RelativoDrako.github.io remains the professional landing and capability surface.
- inventory-stream7-rescue remains the operational tooling proof.
- EdgeResilienceLab is public and professionally presentable as work in progress, without being framed as a finished product or production implementation.
- Public-facing text should avoid visible repository-pinning instructions.
- Public-facing text should avoid private deployment instructions.
